# UInt2048 Homebrew Tap

## How do I install these formulae?

`brew install uint2048/tap/<formula>`

Or `brew tap uint2048/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "uint2048/tap"
brew "<formula>"
```

## Documentation

View Homebrew documentation at `brew help`, `man brew` or check [Homebrew's documentation online](https://docs.brew.sh).
