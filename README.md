# Uint2048 Brew

## How do I install these formulae?

`brew install uint2048/brew/<formula>`

Or `brew tap uint2048/brew` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "uint2048/brew"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
